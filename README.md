# nyktree — Portfolio

A minimalist personal portfolio built around a red monochrome visual language, dithered artwork, and subtle interactive motion.

## Overview

The page is intentionally personal without feeling overly casual or corporate. It acts as a visual introduction to my background in computer science, creative coding, digital craft, music, games, art, and technology exploration.

## Features

- Red monochrome interface on a black and grey foundation
- Dithered artwork integrated into the hero section
- Mouse-reactive spotlight and parallax movement
- Animated red rain atmosphere using HTML Canvas
- Cursor-following interaction ring
- Hover motion for projects, links, and interest blocks
- Responsive layout for desktop and mobile screens
- Reduced-motion support for accessibility
- Sections for:
  - About
  - Selected work
  - Creative coding and interests
  - Currently learning
  - Now playing
  - Social and contact links
